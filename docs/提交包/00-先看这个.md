# 先看这个：AgentLens 一页纸

**AgentLens 是给 AI 智能体做「分层归因体检」的测试平台**（传智杯 AI 智能体测试挑战赛 · 路径二）。
它把智能体的一次执行录成分步骤的「思考—行动」链路，对每一步单独断言；失败时自动指出错在哪一层：
规划、选工具、填参数、读结果、知识源，还是安全护栏。

## 我们测了什么

被测对象是一个真实的校园助手智能体「软帮手」：真实大模型 + 6 个只读工具（课表、成绩、考勤、考试、宿舍水电、通知检索）。
数据全部是虚构的演示数据。

| | |
|---|---|
| 测试用例 | **354 条**，覆盖官方七个测试维度；其中 272 条由 LLM 自动生成（**76.8%**） |
| 发现缺陷 | **13 条**，每条都有录制证据和一条复现命令（`02-缺陷清单/`） |
| 归因器自身的准确率 | 159 条注入故障，归到正确层 158 条（**99.4%**） |
| 双轨判定 | 规则判定 + LLM 裁判；LLM 裁判额外抓出 32 条规则看不见的算错数 |
| 可复现 | 录制 / 回放：在干净环境、不联网、没有 API key 的情况下复跑，354 条结论逐条一致 |

## 最值得看的三个发现

1. **D-001 算错加权平均**（L4 结果解读）：数据拿对了，自己算加权平均分 / 绩点时算错，
   换四种说法复现 19 次。规则断言看不出来，是 LLM 裁判逐项复算抓到的。
2. **D-003 / D-009 护栏防线只剩模型一层**（L6）：查室友成绩会被拦，但换个说法、冒充辅导员、
   被拒后再说「他同意了」，规则护栏都没触发。模型自己拒绝了，没有泄露，但护栏形同虚设。
3. **D-012 → D-007 一条因果链**（L5 → L1）：通知检索只匹配标题和摘要，「通知」「公告」这种最自然的词零召回，
   于是智能体换词连搜 3–10 次。分层归因把「慢」的根因定位到工具设计，而不是模型。

## 5 分钟验证

1. 打开 `05-报告/` 里任意一份 `report.html`：断网可看，维度 × 归因层热力图 + 每条失败的链路与证据。
2. 读 `02-缺陷清单/缺陷清单.md`：13 条缺陷，每条带复现用例名。
3. 想亲手复跑：按 `07-复现指南.md`，装完依赖三条命令，结果应与报告完全一致。
